# Конфигурация MeshCore — 7 устройств

Роль в MeshCore задаётся прошивкой: **companion radio** (BLE/USB, конфиг через
приложение), **repeater** и **room server** (консоль по serial/BLE, команды CLI).
Синтаксис команд сверить с `help` вашей версии прошивки — ниже стандартный набор
консоли repeater/room server.

## Экономия батареи на узлах без розетки (ГРЯДА, РЕПИТЕР-ВОСТОК, АДМИНИСТРАЦИЯ)

Эти три узла живут от батарей, поэтому всё лишнее выключаем — потребление падает
с ~0.6 до ~0.3 Вт, ресурс удваивается:

```
set ble.off        # BLE нужен только на монтаже, дальше выключить
set screen.off     # OLED ест до 15 мА непрерывно
set advert.interval 240
```

Точные имена команд сверить с `help` вашей версии прошивки. После настройки —
ночной прогон на реальной батарее (см. чек-листы, раздел про автоотключение).

## Общие радиопараметры (все 6 устройств, задать явно)

| параметр | значение | почему |
|---|---|---|
| частота | **868.7 МГц** | безлицензионный диапазон РФ 868.7–869.2 (нижний край, как в спецификации) |
| BW | **62.5 кГц** | чувствительность −132.5 dBm |
| SF | **9** | +5 dB чувствительности против SF7 — площадка в лесу |
| CR | **5** (4/5) | баланс скорости и стойкости |
| TX | **14 dBm** | по спецификации заказчика, задать явно (дефолт прошивки может быть выше) |

> ⚠ **ЭИИМ.** 14 dBm на панель 8 dBi = 22 dBm ЭИИМ (158 мВт) — больше 100 мВт,
> разрешённых в 868.7–869.2 (и тем более больше 25 мВт по консервативному чтению).
> Если равняться на ЭИИМ ≤ 100 мВт: companion с панелью — `set tx 12`
> (12+8=20 dBm ЭИИМ), узлы с коллинеарками 6 dBi — `set tx 14` (20 dBm ЭИИМ).
> Худший путь при этом остаётся +14 dB на мокрой листве (магистраль не трогается).
> Решение за заказчиком — обе цифры уже посчитаны.

## РС-1 · АДМИНИСТРАЦИЯ — room server

```
set name АДМИНИСТРАЦИЯ
set lat 54.679460
set lon 35.082422
set radio 868.7,62.5,9,5
set tx 14
password <АДМИН_ПАРОЛЬ>          # сменить дефолтный до выезда!
set guest.password <ГОСТЕВОЙ>
set advert.interval 240
```

Антенна: коллинеарная всенаправленная 6 dBi, подвес 6 м (дерево, верёвка+карабин).
После первого старта записать публичный ключ узла в таблицу ключей (см. ниже).

## РТ-1 · ГРЯДА — repeater

```
set name ГРЯДА
set lat 54.685155
set lon 35.091173
set radio 868.7,62.5,9,5
set tx 14
set repeat on
password <АДМИН_ПАРОЛЬ>
set advert.interval 240
```

Антенна: коллинеарная 6 dBi, подвес 6 м. Interference Threshold — дефолт 14 dB
(проверка на месте по чек-листу).

## РТ-2 · РЕПИТЕР-ВОСТОК — repeater (резерв + восточное плечо)

```
set name РЕПИТЕР-ВОСТОК
set lat 54.680307
set lon 35.096607
set radio 868.7,62.5,9,5
set tx 14
set repeat on
password <АДМИН_ПАРОЛЬ>
set advert.interval 240
```

Антенна: коллинеарная 6 dBi, подвес 4–5 м на строение у Танцплощадки.
При отказе ГРЯДЫ сеть живёт через него (+21.8 dB на мокрой листве); в штатном
режиме несёт трафик КИНОБАРА.

## Companion ×4 (конфиг через приложение MeshCore)

| имя | широта | долгота | подвес | антенна | азимут панели | tx |
|---|---|---|---|---|---|---|
| СЕВЕРНЫЙ ГОРОД | 54.683441 | 35.082028 | 6 м (дерево) | панель 8 dBi | **177°** (на АДМ) | 14 (или 12, см. ЭИИМ) |
| КИНОБАР | 54.687750 | 35.093983 | 4–5 м (строение) | панель 8 dBi | **168°** (на РЕПИТЕР-ВОСТОК) | 14 (или 12) |
| ФУДКОРТ | 54.678741 | 35.091922 | 4–5 м (строение) | панель 8 dBi | **277°** (на АДМ) | 14 (или 12) |
| WONDER WAY | 54.681623 | 35.077268 | 4–5 м (строение) | панель 8 dBi | **126°** (на АДМ) | 14 (или 12) |

В приложении: Radio → Frequency 868.7, BW 62.5, SF 9, CR 5; выключить
автовыбор региона, если он ставит EU868 (869.525).

## Ключи

1. Прошить все 6 устройств, дать каждому загрузиться и сгенерировать identity-ключ.
2. Снять публичные ключи (`get public.key` в консоли / экран About в приложении)
   и заполнить таблицу — она же идёт в конфиг синхронизации (docs/deploy/sync-protocol.md):

| узел | роль | public key |
|---|---|---|
| АДМИНИСТРАЦИЯ | room server | `___` |
| ГРЯДА | repeater | `___` |
| РЕПИТЕР-ВОСТОК | repeater | `___` |
| СЕВЕРНЫЙ ГОРОД | companion | `___` |
| КИНОБАР | companion | `___` |
| ФУДКОРТ | companion | `___` |
| WONDER WAY | companion | `___` |

3. На room server задать пароли (админ + гостевой) и внести companion-ключи в
   список доверенных клиентов комнаты. Companion подключаются к комнате по
   гостевому паролю, админ-пароль не покидает бумажный конверт.
